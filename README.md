# AI-Cinematic-Video-Studio

استوديو لإنتاج فيديوهات موشن جرافيك سينمائية عربية (RTL) بالكود، باستخدام **Remotion + React + TypeScript**، مع تصدير تلقائي إلى **MP4 بدقة 1080p** عبر GitHub Actions.
كل الأدوات مجانية ومفتوحة المصدر، ولا يوجد أي API مدفوع أو كريدتس.

## الفيديو الأول

**«منصة الدعم التعليمي المكثف»** — 60 ثانية · 1920×1080 · 30 إطارًا/ثانية · ألوان كحلية ووردية غبارية.

| # | المشهد | المدة |
|---|--------|-------|
| 1 | الافتتاح: «لكل طالبة إيقاعها في التعلّم» | 7 ث |
| 2 | التحدّي: تفاوت المستويات، ضيق الوقت، صعوبة المتابعة | 9 ث |
| 3 | تقديم المنصة: الخطة · التدريب · المتابعة | 9 ث |
| 4 | كيف تعمل المنصة؟ (4 خطوات) | 12 ث |
| 5 | لوحة المتابعة (بيانات توضيحية) | 10 ث |
| 6 | النتيجة | 8 ث |
| 7 | الخاتمة وتوقيع «نهى — English Teacher» | 5 ث |

## تشغيل أول فيديو وتحميل ملف MP4 (من GitHub مباشرة)

1. ارفعي ملفات المشروع إلى المستودع (فرع `main`)، ثم افتحي المستودع على GitHub.
2. اضغطي تبويب **Actions** في أعلى الصفحة.
3. اختاري من القائمة اليسرى **Render video (MP4 1080p)**.
   - إن ظهرت رسالة *"Workflows aren't being run on this repository"* فاضغطي **I understand my workflows, go ahead and enable them**.
4. اضغطي **Run workflow** (يمين الصفحة) واتركي الإعدادات الافتراضية:
   - `composition` = `IntensiveSupport`
   - `voiceover` = `generate` (تعليق صوتي عربي مجاني)
   - `voice` = `ar-SA-ZariyahNeural` (صوت أنثوي سعودي)

   ثم اضغطي زر **Run workflow** الأخضر.
5. انتظري نحو 10–20 دقيقة حتى تظهر علامة ✅ بجانب التشغيل. افتحي التشغيل بالضغط على اسمه.
6. انزلي إلى قسم **Artifacts** في أسفل الصفحة، واضغطي على **`video-<رقم>`** لتحميل ملف ZIP.
7. فكّي الضغط: ستجدين `IntensiveSupport.mp4` (الفيديو) و`poster.png` (صورة الغلاف). الملفات تُحفظ 30 يومًا.

> التشغيل يحدث أيضًا تلقائيًا عند كل `push` على `main` يغيّر ملفات المشروع (`src` أو `content` أو `public` …).

## بنية المشروع

```
content/video-01.json         ← المصدر الوحيد للنص والمدد (التعليق + الترجمة + توقيت المشاهد)
src/
  Root.tsx, Video.tsx         ← تعريف الـ Composition وتركيب المشاهد
  scenes/                     ← 7 مشاهد (Hook, Challenge, Intro, How, Progress, Impact, Outro)
  components/                 ← الخلفية السينمائية، النص المتحرك، البطاقات، الأيقونات، الترجمة، الصوت
  data/timeline.ts            ← حساب التوقيتات والمزامنة مع مدة الصوت الفعلية
  theme.ts, fonts.ts          ← الألوان (كحلي/وردي غباري) وخط Cairo
scripts/
  generate_voiceover.py       ← تعليق صوتي عربي مجاني (edge-tts) + قياس المدة + ضبط السرعة
  generate_music.py           ← يولّد موسيقى خلفية أصلية (CC0)
  check-privacy.mjs           ← يمنع رفع بيانات الطالبات/صورهن
public/audio/manifest.json    ← يربط الصوت بالمشاهد (يُحدَّث تلقائيًا بالسكربتات)
.github/workflows/render-video.yml
```

## دعم RTL والعربية

- كل مشهد داخل حاوية `dir="rtl"` و`lang="ar"`، وتُرتَّب العناصر من اليمين إلى اليسار (أول بطاقة/خطوة تظهر على اليمين).
- النص يتحرك **كلمة بكلمة** (لا حرفًا بحرف) حتى لا ينكسر اتصال الحروف العربية.
- الخط Cairo (رخصة OFL) يدعم العربية واللاتينية، ويُحمَّل عبر `@remotion/google-fonts`.
- الإنجليزية (مثل English Teacher) تُعرض داخل عناصر `dir="ltr"`.

## نظام الصوت والمزامنة

**التعليق الصوتي** (مجاني، بلا مفتاح API):
- `generate_voiceover.py` يولّد ملف MP3 لكل مشهد بصوت عصبي عربي عبر حزمة `edge-tts`.
- يقيس المدة الفعلية بـ ffprobe، فإن كان أطول من المشهد سرّعه حتى 1.3× مع الحفاظ على طبقة الصوت، وإن لم يتّسع يتوقف ويطلب تقصير النص.
- يكتب `public/audio/manifest.json`؛ ومنه يحسب `timeline.ts` نافذة الكلام لكل مشهد.
- **الترجمة المحروقة** على الفيديو وظهور عناصر المشهد (البطاقات، الخطوات، النتائج) تتبع مقاطع الكلام نفسها، فتتزامن مع الصوت تلقائيًا.

**الموسيقى الخلفية:**
- الملف `public/audio/music/background.mp3` موسيقى أصلية **وُلّدت برمجيًا من الصفر** بواسطة `generate_music.py`، فلا توجد تسجيلات طرف ثالث ولا حقوق (CC0 / ملكية عامة).
- تنخفض الموسيقى تلقائيًا (ducking) أثناء الكلام وترتفع بين المقاطع، مع تلاشٍ في البداية والنهاية.
- لاستخدام موسيقى أخرى مرخّصة: ضعي الملف مكان `background.mp3` وحدّثي حقل `license` في `public/audio/manifest.json` (واحتفظي بإثبات الترخيص/الإسناد إن كان مطلوبًا).

**خيارات `voiceover` عند التشغيل اليدوي:**

| الخيار | المعنى |
|--------|--------|
| `generate` | توليد التعليق بـ edge-tts أثناء التشغيل (الافتراضي) |
| `recordings` | معالجة تسجيلاتك الخاصة الموضوعة في `content/voice-recordings/<scene-id>.mp3` (`hook, challenge, intro, how, progress, impact, outro`) — الأصول لا تُعدَّل أبدًا |
| `committed` | استخدام ملفات `public/audio/voice/` المرفوعة مسبقًا في المستودع |
| `none` | بدون تعليق (موسيقى فقط) |

> إن تعذّر توليد الصوت في تشغيل ما (قد تحجب خدمة Edge أحيانًا عناوين GitHub)، يكتمل التصدير بالموسيقى فقط مع تحذير أصفر. أعيدي التشغيل، أو ولّدي الصوت محليًا وارفعي `public/audio/voice/` ثم اختاري `committed`.

## التشغيل على جهازك (اختياري)

```bash
npm install            # أول مرة فقط، ثم ارفعي ملف package-lock.json الناتج
npm run dev            # استوديو Remotion للمعاينة
pip install edge-tts numpy
npm run audio          # يولّد الصوت والموسيقى
npm run render         # يصدّر out/intensive-support-01.mp4
```

يلزم Node 20+ (يُفضّل 22)، وPython 3، وffmpeg.

## الخصوصية

المستودع **عام**، لذلك:
- لا تُرفع بيانات الطالبات أو صورهن أو ملفات الدرجات (`.xlsx` / `.csv` …) — تمنعها `.gitignore` ويفحصها `npm run check:privacy` في بداية كل تشغيل (يفشل التشغيل إن وجد شيئًا مشبوهًا).
- الفيديو يستخدم رسومًا توضيحية فقط، وأرقام لوحة المتابعة **توضيحية وموسومة بذلك** داخل الفيديو.
- إن أردتِ يومًا عرض بيانات حقيقية، فاستخدمي مستودعًا **خاصًا** منفصلًا.

## إضافة فيديو جديد

1. انسخي `content/video-01.json` إلى `content/video-02.json` وعدّلي النص والمدد.
2. أضيفي مشاهدك في `src/scenes/` وسجّليها في `src/Video.tsx`، وأضيفي `<Composition>` جديدًا في `src/Root.tsx`.
3. شغّلي الـ workflow واكتبي معرّف الـ composition الجديد في خانة `composition`.
